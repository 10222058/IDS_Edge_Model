Control Plane

Register · Devices · Unregister · Rotate

Control service

Register device

Whitelist + ACL + mTLS client cert via FastAPI. Bundle is one-time download (≤5 min).

Registered devices

Unregister device

Removes ACL + password line; optional allow-list IP removal when no other device shares it.

Rotate server cert (same CA)

Re-issues gateway server.* with subjectAltName=IP:…. Does not rotate the CA or client certs.

Rotate CA (break-glass)

New CA + server + reissue all registry device client certs. You must redistribute every bundle. Only redistribute when status is ok (not reload_failed).
